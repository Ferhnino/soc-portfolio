# Ferh Laxamana — SOC analyst & SOC engineer portfolio

A single-page portfolio (`index.html` + `style.css`) hosted on GitHub Pages. It covers SOC analysis,
detection engineering, SOC engineering (log ingestion and automation), and a featured personal
build, **threat-feed-lite**, a lightweight threat-intelligence aggregator.

## Run locally

Open `index.html` in a browser. No build step.

## Deploy

Settings → Pages → Deploy from a branch → `main` / root.
